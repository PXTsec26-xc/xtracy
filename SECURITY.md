# Security & Responsible Vulnerability Disclosure Policy

**Project**: XTRACY Cybersecurity Intelligence Platform
**Maintainer**: Elliot PXT / PXT ([@PXTsec26-xc](https://github.com/PXTsec26-xc))
**Live Production URL**: `https://xtracy.vercel.app`

---

## 🛡️ Responsible Disclosure Commitment

XTRACY is committed to maintaining a high standard of security, transparency, and defensive privacy. If you discover a security vulnerability or security weakness in XTRACY, we encourage you to report it responsibly.

---

## 📋 Reporting a Vulnerability

Please report potential security issues directly via GitHub Security Advisories or private security communications:

1. **Email / Contact**: Reach out via official PXT sec26 security contact channels or open a private security advisory on the GitHub repository ([`https://github.com/PXTsec26-xc/xtracy`](https://github.com/PXTsec26-xc/xtracy)).
2. **Include Technical Details**:
   - Vulnerability classification (e.g. SSRF bypass, XSS, broken access control).
   - Step-by-step reproduction steps.
   - Proof-of-Concept payload (if applicable).
   - Impact assessment on user data or platform integrity.

---

## 🚫 Safe Harbor & Rules of Engagement

- **Defensive & Non-Disruptive Testing Only**: Do not execute Denial of Service (DoS) attacks, automated high-volume brute forcing, or attempt to access or modify data belonging to other users.
- **Privacy Protection**: Never access or leak user private vault data or personal environment credentials.
- **Coordination**: Allow reasonable time for technical review and remediation before public disclosure.
